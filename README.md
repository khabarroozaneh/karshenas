# وردپرس جو — برنامهٔ آفلاین مدیریت تماس

یک برنامهٔ وب پیشرونده (PWA) کاملاً آفلاین برای تماس مستقیم با لیدها و مدیریت قرارها و قراردادهای کارشناس. همه‌چیز استاتیک است: بدون سرور، بدون دیتابیس، بدون نیاز به build.

## ساختار پروژه

```
.
├── index.html              # صفحه فرود: لینک برنامه
├── .github/workflows/deploy.yml  # استقرار خودکار روی GitHub Pages
├── RAVAND/                 # خط لوله تولید لید (تشخیص وردپرس + تست سرعت)
│   └── PIPELINE/Run.bat    # خودکارسازی کل خط لوله + سرور محلی
└── wpjoo-expert-app/       # برنامه کارشناس: تماس اول، قرارها، قراردادها، تقویم شمسی
```

## خط لوله تولید لید

برای تبدیل بانک اکسل به فید پنل کارشناس، `RAVAND/PIPELINE/Run.bat` را اجرا کنید.
راهنمای کامل در [RAVAND/PIPELINE/README.md](RAVAND/PIPELINE/README.md) آمده است.

## انتشار روی GitHub Pages

۱. یک ریپوزیتوری بسازید و این پوشه را پوش (push) کنید.
۲. در تنظیمات ریپوزیتوری به **Settings → Pages** بروید.
۳. بخش **Build and deployment** را روی **GitHub Actions** قرار دهید.
۴. هر push روی شاخه `main` به‌صورت خودکار استقرار پیدا می‌کند. می‌توانید از تب **Actions → Deploy to GitHub Pages** هم دستی اجرا کنید.

پس از استقرار، برنامه‌ها روی این آدرس‌ها در دسترسند:

- صفحه فرود: `https://<کاربر>.github.io/<ریپوزیتوری>/`
- پنل کارشناس: `https://<کاربر>.github.io/<ریپوزیتوری>/wpjoo-expert-app/`

تمام مسیرها نسبی هستند، بنابراین پروژه در زیرپوشه هم درست کار می‌کند. اگر ریپو را روی دامنه شخصی یا ریشه (`<کاربر>.github.io`) منتشر می‌کنید هم نیازی به تغییر نیست.

> **نکته:** ریپوزیتوری روی GitHub Pages رایگان باید **public** باشد. دیتای کاربران به سرور ارسال نمی‌شود و در ریپوزیتوری هم قرار نمی‌گیرد؛ فقط کد برنامه عمومی است.

## نصب روی گوشی

برنامه را در مرورگر گوشی باز کنید، از منوی مرورگر **«افزودن به صفحه اصلی»** را انتخاب کنید و از آن به بعد فقط از همان آیکون استفاده کنید.

## نکات مهم درباره داده‌ها

- داده‌ها فقط در `localStorage` **همان مرورگر یا برنامه نصب‌شده روی همان دستگاه** ذخیره می‌شوند و به جایی ارسال نمی‌شوند.
- مرورگرهای مختلف و حتی برنامه نصب‌شده در برابر تب مرورگر، فضای ذخیره‌سازی جداگانه دارند. یک روش را انتخاب کنید و همیشه از همان استفاده کنید.
- قبل از پاک‌کردن داده‌های مرورگر یا تعویض گوشی، از دکمه **«پشتیبان کامل داده‌ها»** (داخل پنل کارشناس) خروجی JSON بگیرید و در دستگاه جدید import کنید.
- پنل کارشناس دکمهٔ جداگانه برای پاک‌کردن **داده‌های ورودی** دارد («پاک‌کردن لیدهای ورودی» در بخش ورود) که فقط داده‌های بارگذاری‌شده را با تأیید دو مرحله‌ای حذف می‌کند و گزارش‌ها، قرارها و قراردادها را حفظ می‌کند. پاک‌کردن گزارش‌ها و پاک‌کردن کل داده‌ها هم دکمهٔ جداگانهٔ خودشان را دارند.
- حالت ناشناس (incognito) داده‌ها را بعد از بستن حذف می‌کند.

## توسعه و تست

فایل‌ها استاتیک‌اند؛ کافی است `index.html` را در مرورگر باز کنید. برای تست تقویم شمسی:

```bash
node wpjoo-expert-app/jalali.test.js
```
