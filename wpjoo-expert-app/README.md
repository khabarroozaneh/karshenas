# پنل کارشناس وردپرس جو

فایل JSON خروجی منشی را بارگذاری کنید. فقط گزارش‌های دارای وضعیت `قرار جلسه با کارشناس` نمایش داده می‌شوند. قرارها بر اساس زمان مرتب می‌شوند و قرارهای ۲۴ ساعت آینده هشدار می‌گیرند.

دو دکمهٔ پاک‌کردن با تأیید دو مرحله‌ای: «پاک‌کردن ورودی‌ها» فقط قرارهای بارگذاری‌شده از JSON منشی (شامل «سایت نداشتند») را حذف می‌کند و گزارش‌های کارشناس را نگه می‌دارد؛ «پاک‌کردن اطلاعات» همه‌چیز (قرارها و گزارش‌ها) را پاک می‌کند.
