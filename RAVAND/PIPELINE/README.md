# وردپرس جو — خط لوله تولید لید

از بانک اکسل تا تماس مستقیم کارشناس با لید، کاملاً آفلاین.

```
بانک اکسل ──→ [مرحله ۱] تشخیص وردپرس ──→ [مرحله ۲] تست سرعت ──→ فید کارشناس
                                                                    │
                                                                    ▼
                                                       پنل کارشناس (wpjoo-expert-app)
                                                       تماس اول، قرارها، قراردادها
```

## شروع سریع

```bat
RAVAND\PIPELINE\Run.bat
```

چهار حالت:

| حالت | توضیح |
|------|--------|
| `1` **پنل خط لوله (پیشنهادی)** | پنل کاربرپسند روی `http://127.0.0.1:8124`. بانک را از داخل پنل انتخاب می‌کنید، برنامه خودسرانه سراغ بانک نمی‌رود. |
| `2` اجرای کامل | تشخیص وردپرس + تست سرعت همه سایت‌ها با بانک پیش‌فرض. سایت‌های تست‌شده در کش ذخیره می‌شوند تا دفعه بعد سریع‌تر باشد. |
| `3` بازسازی فید | فقط از نتایج ذخیره‌شده (`speed_cache.json` + `pipeline_report.json`)، بدون تست زنده. |
| `4` سرور محلی | پنل کارشناس را روی `http://127.0.0.1:8123` سرو می‌کند. |

### پنل خط لوله (`panel.py`)

اجرای مستقیم:

```bat
cd RAVAND\PIPELINE
python panel.py
```

سپس در مرورگر `http://127.0.0.1:8124/` باز می‌شود. مراحل:

1. **انتخاب بانک** — فایل‌های اکسل موجود در `RAVAND/1/DATA` فهرست می‌شوند و یکی را انتخاب می‌کنید.
2. **حالت اجرا** — «اجرای کامل» یا «بازسازی فید از کش».
3. **پیشرفت** — لاگ زندهٔ خط لوله، تعداد لیدهای فید و وضعیت اجرا.

خط لوله فقط روی بانکی که شما انتخاب کرده‌اید اجرا می‌شود.

## مراحل جریان کار

### ۱) خط لوله (خط تولید فید)

```bat
cd RAVAND\PIPELINE
python pipeline.py                      :: کامل
python pipeline.py --cached-only        :: سریع از کش
python pipeline.py --limit 20           :: فقط ۲۰ ردیف اول
python pipeline.py --skip-speed         :: بدون تست سرعت
```

خروجی‌ها در `RAVAND/PIPELINE/OUTPUT/`:

- **`secretary_feed.json`** — فید پنل کارشناس (نام فایل برای سازگاری قدیمی حفظ شده است). هر لید شامل:
  - چهار فیلد اجباری: `ownerName` / `name` / `url` / `phone`
  - `plugins` و `pluginsFa` — افزونه‌های نصب‌شده + توضیح ساده
  - `speed` — معیارهای Lighthouse (`score`, `fcp`, `lcp`, `cls`, `tbt`, `si`, `ttfb`, `testedVia`, `opportunities`)
  - `issues` — مشکلات سایت به زبان ساده برای کارشناس موقع تماس
  - `wordpressFacts` — جزئیات تشخیص وردپرس
- **`pipeline_report.json`** — گزارش کامل هر سایت
- **`speed_cache.json`** — کش نتایج Lighthouse (برای اجرای سریع بعدی)

> **نکته:** کارشناس همهٔ این اطلاعات (سرعت، افزونه‌ها، مشکلات، شواهد وردپرس) را در کارت لید، پیش از تماس می‌بیند.

### ۲) پنل کارشناس (`wpjoo-expert-app`)

1. «ورود یا افزودن لید» → **«بارگذاری خودکار فید تازه از خط لوله»** (فید را مستقیم از خروجی خط لوله می‌گیرد) یا فایل JSON را دستی انتخاب کنید.
2. «شروع/ادامه تماس» → هر بار یک لید → کارت لید با اطلاعات کامل فنی:
   - **سرعت سایت:** نمره + بارگذار اصلی + اولین محتوا + پاسخ سرور + قفل صفحه (با اعداد فارسی)
   - **افزونه‌های نصب‌شده:** به صورت چیپ
   - **مشکلات سایت به زبان ساده** — برای ارائه به مشتری
3. گزارش تماس اجباری با نتیجهٔ نهایی: قرارداد در همان تماس، قرار جلسه، پیگیری زمان‌بندی‌شده یا وضعیت‌های پایانی.
4. «گزارش‌ها و خروجی» — خروجی JSON خود-حاوی (گزارش + لید کامل + گزارش جلسه) و پشتیبان کامل، قابل انتقال به دستگاه دیگر.

## ستون‌های بانک اکسل

| ستون | فیلد |
|------|------|

## پیش‌نیازها

- پایتون ۳.۱۰+ با `openpyxl` (`pip install openpyxl`)
- نود جی‌اس ۱۸+ (برای Lighthouse)
- مرورگر مدرن (کروم یا اج)

## عیب‌یابی

- **فید خالی است** — فایل اکسل را بررسی کنید؛ ستون D باید آدرس سایت داشته باشد.
- **تست سرعت ناموفق است** — سرور سایت ممکن است فایروال داشته باشد. خط لوله خودکار با مرورگر edge و اتصال مستقیم دوباره تلاش می‌کند.
- **داده‌های پنل پاک شد** — پنل کارشناس از `localStorage` مرورگر استفاده می‌کند. قبل از پاک‌کردن، «پشتیبان کامل» بگیرید.
- **فید قدیمی است** — `Run.bat` → حالت ۲ (بازسازی فید از کش).
